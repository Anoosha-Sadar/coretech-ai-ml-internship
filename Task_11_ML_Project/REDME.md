# CoreTech AI Client Feedback Sentiment Analyzer

## Project Overview

The AI Client Feedback Sentiment Analyzer is an end-to-end Natural Language Processing (NLP) and Machine Learning solution designed to transform unstructured customer feedback into actionable business intelligence.

The system automatically analyzes customer opinions and classifies feedback into:

* Positive
* Negative
* Neutral
* Irrelevant

In addition to sentiment prediction, the platform provides business-focused insights such as customer satisfaction assessment, risk analysis, confidence scores, and actionable recommendations.

---

## Project Objectives

* Analyze customer feedback using NLP techniques
* Perform sentiment classification on textual data
* Compare multiple machine learning algorithms
* Identify the best-performing model through evaluation and optimization
* Generate meaningful business insights from customer opinions
* Deploy the final solution using Streamlit

---

## Dataset

* Dataset: Twitter Entity Sentiment Analysis Dataset
* Records: 70,000+ Customer Feedback Entries
* Classes: Positive, Negative, Neutral, Irrelevant

The dataset contains real-world customer opinions and brand-related discussions collected from social media platforms.

## Models Evaluated

* Logistic Regression
* Naive Bayes
* Random Forest
* Gradient Boosting
* Extra Trees Classifier

After comprehensive evaluation, the Extra Trees Classifier achieved the best performance and was selected as the final deployment model.

---

## Key Results

| Metric                 | Result                 |
| ---------------------- | ---------------------- |
| Best Model             | Extra Trees Classifier |
| Test Accuracy          | 89.71%                 |
| Cross Validation Score | 89.88%                 |
| Classes Predicted      | 4                      |

The close alignment between testing accuracy and cross-validation score demonstrates strong model stability and generalization capability.
