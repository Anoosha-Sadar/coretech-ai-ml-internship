## Task 03: Data Preprocessing and Feature Engineering

### Objective
Perform complete data preprocessing on a sample client dataset.

### Steps Performed

1. Loaded dataset
2. Handled missing values using mean
3. Removed duplicate records
4. Applied Label Encoding
5. Applied One-Hot Encoding
6. Normalized numerical features using MinMaxScaler
7. Performed Feature Selection using SelectKBest
8. Compared dataset before and after preprocessing
9. Saved cleaned dataset
