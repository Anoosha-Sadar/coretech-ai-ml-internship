# Task 6: Unsupervised Learning - Clustering

## Objective

Perform customer segmentation using clustering techniques.

---

## Dataset

Mall Customers Dataset

Features Used:

- Annual Income (k$)
- Spending Score (1-100)

---

## Steps Performed

### 1. Data Loading

Loaded dataset using Pandas.

### 2. Data Preprocessing

- Checked missing values
- Selected relevant features
- Applied Standard Scaling

### 3. K-Means Clustering

- Used Elbow Method
- Selected optimal K = 5
- Created customer segments

### 4. Cluster Visualization

Visualized customer groups using scatter plots.

### 5. Hierarchical Clustering

- Generated dendrogram
- Applied Agglomerative Clustering
- Compared results with K-Means

### 6. Business Insights

Generated customer profiles and marketing strategies.

---

## Results

- Optimal Clusters = 5
- Clear customer segmentation achieved
- Both algorithms produced meaningful groups
